# Export Checklist

Before showing the video at the first-birthday party:

- [ ] Final length is between 5:20 and 5:55.
- [ ] File is MP4.
- [ ] Resolution is 1920x1080.
- [ ] Aspect ratio is 16:9.
- [ ] Captions are readable on a TV.
- [ ] Audio is not too loud or too quiet.
- [ ] No photo is accidentally cut off in an awkward way.
- [ ] Vertical clips have consistent side treatment.
- [ ] Similar photos are not repeated too closely.
- [ ] The ending holds long enough for guests to read the final message.
- [ ] Final file is saved in `exports`.
